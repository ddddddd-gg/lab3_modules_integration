# Описание тестирования интеграции

Тестирование автоматизированно с помощью библиотки unittest и сохранено в файл tests\integration_tests.py. Оно содержит 4 теста, проверяющих корректность взаимодействия между модулями.

# Тесты
1. Проверка соединения с модулем обработки матрицы
   Тест проходит успешно, если сервер возвращает код 405 - сервер распознал запрос от клиента.
2. Проверка соединения с модулем вывода результата
   Тест проходит успешно, если сервер возвращает код 405 - сервер распознал запрос от клиента.
3. Проверка корректности передачи данных в модуль обработки матрицы
   Тест проходит успешно, если сервер возвращает код 200 - работа функции прошла успешно.
4. Проверка корректности передачи данных в модуль вывода результа
   Тест проходит успешно, если сервер возвращает код 200 - работа функции прошла успешно.
