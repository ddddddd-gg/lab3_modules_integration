# Описание архитектуры взаимодействия
Система состоит из 4 программных модулей:
1. main.py (управляющий модуль)- выполняет роль клиента и координирует передачу данных
2. matrix_input (модуль ввода данных) - веб-сервер ввода данных, развернут на http://localhost:5000/input
3. matrix_processing.py (модуль обработки данных) - веб-сервер обработки данных (транспонирования), развернут на http://localhost:5001/transpose
4. matrix_output.py (модуль вывода данных) - веб-сервер вывода данных, развернуть на http://localhost:5002/output

# Описание протоколов и форматов
В работе использовался транспортный протокол REST API (JSON), который используется для обмена данными через HTTP. Он позволяет приложениям обмениваться данными независимо от языков программирования и платформ. Сервер предоставляет ресурсы в виде данных (JSON), а клиент получает к ним доступ с помощью стандартных HTTP-запросов.
JSON - легкий, читаемый формат сообщений.
