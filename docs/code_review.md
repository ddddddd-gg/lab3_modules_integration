# 1. Инструмент и параметры проверки
Проверка исходного кода (`src/`) и тестовых модулей (`tests/`) на соответствие стандарту оформления кода Python **PEP 8** выполнена с помощью статического анализатора `flake8`:

```bash
flake8 src/ tests/ --max-line-length=100
```

# 2. Результаты первичной проверки и выявленные замечания
При первом запуске анализатора были выявлены следующие замечания стилистического и структурного характера:
- `E722 do not use bare 'except'` — использование неконкретизированного перехвата исключений `except:` без указания типа ошибки в модулях `src/main.py` и `src/matrix_output.py`.
- `E302 expected 2 blank lines, found 1` — недостаточное количество пустых строк перед объявлением функций верхнего уровня.
- `W293 blank line contains whitespace` — наличие лишних пробелов на пустых строках.
- `E501 line too long` — превышение установленного лимита длины строки в 100 символов.
- `F401 'pytest' imported but unused` - модуль импортирован, но не использован

# 3. Внесённые исправления
Все выявленные замечания были устранены:
- общие блоки `except:` заменены на перехват конкретных исключений (`except ValueError:`), а избыточный блок `try/except` при импорте стандартных библиотек удалён;
- добавлены по две пустые строки перед каждым объявлением функции верхнего уровня;
- удалены пробелы на пустых строках и в конце строк;
- длинные выражения разбиты на несколько строк в соответствии с ограничением в 100 символов.

# 4. Результат повторной проверки
Повторный запуск команды:

```bash
flake8 src/ tests/ --max-line-length=100
```

**Результат:** ошибок и предупреждений не выявлено (код возврата `0`).
