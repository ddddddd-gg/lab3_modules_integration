# Название и назначение
Этот репозиторий содержит код программы "Транспонирование", которая выполняет математическую операцию транспонирования над введенной пользователем матрицей  


# Требования к окружению
Windows/MacOS/Linux


# Инструкция по запуску
1. Клонировать репозиторий 
```bash
git clone https://github.com/ddddddd-gg/lab3_modules_integration
```
2. Открыть терминал в папке ./project/src
3. Выполнить команды для подключения серверов
```
python matrix_input.py
python matrix_processing.py
python matrix_output.py
```
4. Выполнить команду
```
python main.py
```

# Выбранная стратегия ветвеления - GitHubFlow
Требования при таком подходе следующие: в коде в мастер-ветке не допускаются ошибки,
и он должен быть готов к развертыванию в любой момент,
а чтобы начать разрабатывать новую функцию, необходимо создать feature-ветку в master-ветке
и дать ей очевидное для всех имя. Этот подход позволяет
проще понимать и организовывать свою работу.
